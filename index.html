03. Projects

A selection of things I've built.

Featured Project

CHUD.AI — Facial Geometry Analysis

An AI-powered facial geometry analysis engine with a real-time browser dashboard. Uses Google MediaPipe Face Mesh to track 468 facial landmarks and computes aesthetic metrics including Canthal Tilt, Facial Width-to-Height Ratio, Midface Ratio, bilateral Symmetry, and Golden Ratio adherence. Runs a 10-second averaged scan to produce a locked final score.

  • Python
  • Flask
  • MediaPipe
  • NumPy
  • JavaScript
Music → Sheet

Featured Project

Music to Sheet Converter

A full-stack application that converts MP3 / WAV audio files into guitar tablature and sheet music notation using audio signal processing. Users upload an audio file through a React UI; a Flask backend uses Librosa and NumPy to analyse the signal and generate playable guitar tabs in the browser. MIDI and PDF export coming soon.

  • React 19
  • Vite
  • Flask
  • Librosa
  • NumPy
  • TailwindCSS
